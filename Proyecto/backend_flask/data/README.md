# Catálogos agrícolas (borrador)

Aquí se podrán guardar archivos YAML con datos agrícolas **verificados**.
No se incluye información de siembra, dosificación, rendimientos ni recomendaciones
ficticias. Antes de publicar datos, documentar la fuente, fecha de consulta,
unidad, zona geográfica y criterio de validación.

`cultivos.example.yaml` solo demuestra la forma del archivo.
**No debe importarse como catálogo real.**
